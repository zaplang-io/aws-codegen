## How this was produced & validated

- **Models:** `tools/sync-models.py` snapshots the manifest's services from the pinned botocore wheel; the pin is unchanged. The CI *drift* check and the *determinism* check (both the shell step and the `all_checked_in_packages_are_current` Rust test) regenerate every package and diff byte-for-byte.

- **XML/query collection serialization (#426):** the query/ec2 emitter emits a per-shape `<shape>_to_query(p, prefix, v)` free function for each nested structure (recursion via function calls, so cyclic shapes terminate and serializers are shared across ops); top-level members inline in the method with literal keys, so already-generated services regenerate byte-identically. Lists of structures build `Name.member.N.<field>` (wrapped) / `Name.N.<field>` (flattened / ec2) keys; maps use the codec's `query_map`/`query_flat_map` (`Name.entry.N.key/value`). The rest-xml emitter builds lists/maps of structures and the implicit document body from the `rest_xml_struct` primitive, and renders booleans through a per-file `<prefix>_xml_bool` helper (the rest-xml codec has no bool helper). Map keys are emitted **sorted** for a deterministic body (AWS maps are order-insensitive), matching #424.

- **Host-only gate (no Docker):** `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test` (incl. the byte-diff reconstructions + the determinism regen), and the Python SigV4 oracles (`tools/verify_*.py`) all pass. New byte-diff goldens span the unlocked shapes — a synthetic awsQuery body (nested struct + wrapped list-of-structs + wrapped map + flattened list-of-structs; `query_synth_do_thing`) and a synthetic rest-xml body (bool + nested struct + wrapped list-of-structs + wrapped map + flattened list-of-structs; `restxml_synth_collections`) — each reconstructed from the generated source, SigV4-signed, and independently reproduced by `tools/verify_xml_requests.py`. Real-service call-sequence locks cover `autoscaling:CreateAutoScalingGroup` (nested + list-of-struct), `sns:CreatePlatformApplication` (map), `ec2` Describe* (Filters list-of-struct), and `route53:ChangeResourceRecordSets` (implicit document body).

- **Front-end compile sanity:** the emitted serializer idioms (per-shape `_to_query` functions, `query_key` prefixing, index-loop list-of-struct keys, `rest_xml_struct` in loops, the `_xml_bool` helper, `sorted(dict.keys())` map iteration) were checked through a current `zap` front-end (`cargo build -p zapc`; `zap ir`) on standalone modules. Full-client compile + end-to-end byte-diff run in CI (best-effort, see #429) under the toolchain image.

- **Docker was not run** (it kernel-panics the maintainer's host). The toolchain image steps remain CI-only and best-effort.
