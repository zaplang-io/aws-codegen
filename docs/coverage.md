- **nested & collection JSON document bodies** (#424): awsJson + rest-json bodies with a nested structure, map, or list-of-structures member. `@derive(Json)` handles scalars + scalar lists; the rest is skipped. The single biggest unlock.
- **HTTP binding: bool / timestamp / list / map** (#425): rest-json/rest-xml bind only string/enum/int to uri/query/header; bool, timestamp, and list/map bindings are skipped.
- **query + rest-xml non-scalar bodies** (#426): query/ec2/rest-xml codecs serialize flat scalar + scalar-list bodies; structure-lists, nested structures, maps, bool, and implicit rest-xml document bodies are skipped.
- **optional & non-derivable httpPayload** (#427): rest-json/rest-xml httpPayload bodies that are optional or a non-derivable structure.
- **smithy-rpc-v2-cbor protocol** (#428): 25 services excluded (above).
- **generators-as-methods** (#429): generated paginator methods use `yield` inside a method, which the compiler rejects today (I#67 v1); this is why the best-effort *compile* CI step is non-blocking. Byte-diff fidelity is unaffected.
